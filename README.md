# 项目类型：
   跨平台理财资讯与 AI 智能投顾应用
   
# 技术栈 ：
  Uni-app + Vue3 + Pinia 
  
# 核心价值 ：
  一站式理财服务平台，整合股票行情、理财资讯、AI 智能投顾、用户社区等功能

# 核心模块

一、AI智能问答：后台调用大语言模型 + 前端做流式回复效果

二、用户认证和状态管理： 
- ✅ Pinia 状态管理
- ✅ JWT Token 认证
- ✅ 本地持久化存储
- ✅ 请求拦截器封装
- ✅ 统一错误处理

三、数据可视化 - Echarts 图表
  使用 ECharts 实现股票 K 线图、趋势图可视化。考虑兼容性，使用了lime-echart组件

四、高互动理财社区系统
实时内容渲染 、 乐观更新 、 股票标签解析、跨页面状态同步通信 等核心技术
